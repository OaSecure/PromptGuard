# PromptGuard PR 템플릿 레퍼런스

팀원이 GitHub Pull Request를 만들 때 아래 템플릿을 PR 본문에 붙여 넣고 작성한다.

```markdown
## WBS 항목
- WBS 번호:
- 담당자:
- 작업명:

## 변경 내용
-

## 테스트
- [ ] 로컬 테스트 실행
- [ ] GitHub Actions 통과
- [ ] 원문 저장/노출 금지 확인
- [ ] 관련 없는 파일 수정 없음

## 체크리스트
- [ ] main에서 새 브랜치를 만들었음
- [ ] PR 범위가 너무 크지 않음
- [ ] API/DB/화면 계약 변경이 있으면 문서도 수정함
- [ ] 보안/프라이버시 원칙 위반 없음
```

## 작성 기준

- WBS 번호는 `docs/references`의 통합 개발 문서나 WBS 표에서 확인한다.
- 변경 내용은 무엇을 바꿨는지 한눈에 알 수 있게 적는다.
- 테스트에는 실제로 실행한 명령을 PR 본문에 함께 적는다.
- 원문 저장/노출 금지 확인은 `raw_prompt`, 파일 내용, 추출 텍스트, 탐지 원문값, 원본 파일명, full masked prompt가 저장/로그/화면/API 응답에 새로 노출되지 않았는지 확인하는 항목이다.
- 관련 없는 파일 수정 없음은 포맷터, 빌드 산출물, 다른 팀원 작업 범위가 섞이지 않았는지 확인하는 항목이다.
